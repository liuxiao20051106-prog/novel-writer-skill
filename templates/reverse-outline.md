# 反向提纲：《[书名]》

初稿完成后填写：不看正文、凭记忆给每章写一句话，再对照正文补全。写不出来的章节、摘要雷同的连续章节、没有角色选择的章节——就是修订要动的地方。详见 [修订工程](../references/craft-revision.md)。

## 用法

1. 先凭记忆填「一句话摘要」列，允许留空；
2. 对照正文补全，并填「变化」「钩子」「情绪落点」；
3. 填「判定」列：保留 / 压缩 / 合并 / 重写 / 删除；
4. 只看判定列，就能得到一份修订地图——先动结构，再谈句子。
