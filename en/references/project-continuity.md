# Long-Form Continuity and Version Control

Use this guide for novels, serials, and series where facts, timelines, character knowledge, or revisions must remain stable.

> This file covers *what to record*; for *what to feed each generation and how much*, see [Context Budget](context-budget.md).

## Maintain a source of truth

Use [the project overview](../templates/novel-project.md) for durable canon and [the continuity ledger](../templates/continuity-ledger.md) for current state. Record only confirmed facts as canon. Keep proposals and unresolved questions separate.

Track at minimum:

- chronology, duration, travel, and simultaneous events;
- each character’s location, physical state, possessions, goals, and knowledge boundary;
- world rules, costs, limits, and exceptions;
- relationships, promises, mysteries, and planted clues;
- terminology, names, titles, and version provenance.

## Before drafting a chapter

1. Confirm the manuscript version and chapter brief.
2. Read the prior chapter ending and any parallel plotline endpoint.
3. Retrieve only the relevant ledger entries.
4. Identify required transitions, unresolved conflicts, and facts that must not change.
5. Stop and ask the author if two confirmed sources disagree.

## After drafting

Extract new facts and state changes before they are forgotten. Update the ledger only after the author accepts them. Record the chapter and version that supports each change.

Run checks for impossible travel, conflicting ages or dates, forgotten injuries or objects, knowledge leaks, changed rules, duplicate reveals, and unresolved setup.

## Handle revisions safely

- Edit the smallest necessary scope.
- Preserve the original or rely on version control before major rewrites.
- Describe how a retcon propagates to later chapters.
- Do not silently resolve conflicts by inventing new canon.
- Recheck dependent scenes after changing a date, rule, relationship, or reveal.

For very long projects, create a compact context packet per chapter: current brief, relevant canon, last scene state, open threads, and prohibited changes.
