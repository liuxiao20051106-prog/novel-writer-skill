# ChatGPT 配置指南

适用于 ChatGPT (GPT-4/4o/5) 的 Custom GPT 或项目级自定义指令。

## 方式一：创建 Custom GPT

1. 打开 [chatgpt.com](https://chatgpt.com)，点击左侧「探索 GPT」→「创建」
2. 在「说明」栏中粘贴 `SKILL.md` 的**全部正文内容**（去掉 YAML frontmatter 的 `---` 部分），或将以下内容填入：
   - 将 `SKILL.md` 中 `## 核心原则` 到文件末尾的全部内容粘贴进去
3. 在「对话开场白」中可以设置：
   ```
   你好！我是你的小说写作助手。请告诉我——
   - 你想写什么类型的小说？
   - 目前处于哪个阶段（构思 / 写作 / 修改）？
   - 或者直接把你的想法、已有内容发给我。
   ```
4. 保存并发布（可设为「仅自己」或「公开」）

## 方式二：自定义指令

1. ChatGPT → 设置 → 个性化 → 自定义说明
2. 将 `SKILL.md` 中的核心原则和写作要求精简后填入「ChatGPT 应该如何回应？」
3. 适合已有一定写作习惯、只需要 AI 遵循特定风格的用户

## 方式三：每次对话手动粘贴

直接复制 `SKILL.md` 的全部内容，作为每次新对话的第一条消息发送。

## 推荐

- **偶尔使用**：方式三（手动粘贴）
- **长期使用**：方式一（Custom GPT），可以保存上下文和多轮对话
