# 📖 Novel Writer Skill for Claude Code

一个为 Claude Code 打造的写小说全流程助手 skill，覆盖从构思、角色设计、章节写作到修改润色的完整创作流程。

## 功能概览

| 阶段 | 内容 |
|------|------|
| **构思** | 体裁选择、一句话梗概、主题与基调、世界观设定、角色设计（含反派和关系网）、大纲规划 |
| **章节写作** | 写前检查（衔接上一章）、四段式单章结构、场景设计、对话写作、章首衔接 & 章尾勾连 |
| **修改润色** | 宏观编辑（结构/弧线/跨章通读）→ 微观编辑（语言/句式/对话）→ 细节打磨（代入感审查） |

## 核心技法

- **故事结构**：三幕因果链 + 高潮排布 + 次要情节设计
- **角色塑造**：五层角色设计法（原型→外在→创伤→矛盾→弧线）、"想要 vs 需要"框架
- **场景设计**：场景即冲突、长度节奏控制、体裁配比（爽文 3:1 / 言情 2:2 / 悬疑 1:3）
- **对话写作**：六大目标、"阻力"核心原理、打破乒乓球问答
- **节奏控制**：快慢交替、加速/减速手段、高潮"压制-释放"
- **代入感**：视角锁定 + 感官沉浸 + 情感共振 + 处境设计
- **章节衔接**：四种桥接方式（情绪/动作/悬念/时空）+ 多线叙事连续性

## 安装

将 `SKILL.md` 和 `aily-cli-skill.json` 复制到 Claude Code 的 skills 目录：

**用户级安装**（所有项目可用）：
```bash
mkdir -p ~/.claude/skills/novel-writer
cp SKILL.md aily-cli-skill.json ~/.claude/skills/novel-writer/
```

**项目级安装**（仅当前项目可用）：
```bash
mkdir -p .claude/skills/novel-writer
cp SKILL.md aily-cli-skill.json .claude/skills/novel-writer/
```

## 使用

在 Claude Code 中，直接说以下任意一句即可触发：

- 「帮我写小说」
- 「构思一个新故事」
- 「写下一章」
- 「帮我设计一个角色」
- 「润色这一段」

Skill 会自动引导你走完完整的创作流程。

## 项目文件

Skill 会建议维护一个 `novel-project.md` 项目文件，追踪：

- 角色清单（含情感锚点和弧线）
- 角色关系网
- 伏笔追踪
- 章节记录（含 POV 和情感高潮）
- 情感节奏图

## 设计理念

1. **代入感优先** — 一切技巧服务于"让读者忘记在读书"
2. **情感驱动** — 情节 + 情感旅程 = 好小说
3. **角色与情节互为因果** — 不同步生长就会互相拖累
4. **章节之间读得通** — 读者不需要每章重新适应
