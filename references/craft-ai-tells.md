# 去 AI 味（去除机器腔）

仅在「读起来像 AI 写的」「要过 AIGC 检测/编辑初审」「AI 味自查」时读取。核心底线（不写套话、不写升华句、不写三段排比、不写总结式结尾）已内置于 SKILL.md，此处是完整清单与改法。

> 配套工具：先跑 `python scripts/draft_diagnostics.py 章节.md` 拿到客观数据（AI 高频腔密度、句长/段落变异系数、重复表达），再按本文逐处改。
> 相关指南：语言层的「展示 vs 告知」见[文笔与风格](craft-prose-style.md)；情绪被直接命名的问题见[情绪与潜台词](craft-emotion-and-subtext.md)；AI 该做什么、不该做什么见[AI 协作与原创性](ai-collaboration.md)。

**原则：删的是「AI 的姿态」，不是作者的内容。** 拿不准是机器腔还是作者风格的，标出来交给作者定夺，不擅自删。

## 机器腔的根源

模型默认挑「最安全、最常见、最不出错」的表达。安全词全是套话，于是出现三种典型症状：

1. **均匀**——每段一样长、每句一个节奏、情绪没有起伏（可用脚本的变异系数验证）。
2. **周全**——正反都说到、三点并列、结尾一定总结（真实思考是有偏倚的）。
3. **升华**——把一件小事写成宏大叙事，最后一句必定拔高（真实写作往往停在动作或细节上）。

## 十类信号与改法

| # | 信号 | 典型样子 | 改法 |
|---|------|----------|------|
| 1 | 套话开场 | 「众所周知」「值得注意的是」「不难发现」「随着……的发展」 | 整句删掉，直接写事 |
| 2 | 膨胀升华 | 「这不仅仅是一碗面，更是一种态度」 | 删升华，让事实自己说话；或改成角色的具体动作 |
| 3 | 三段排比 | 「更快、更好、更强」「不仅……而且……更是……」 | 数量服从内容；只留最有分量的一个，其余删 |
| 4 | 空转分析 | 「这反映了……彰显了……体现了……」 | 给出真因果，或删 |
| 5 | 模糊归因 | 「专家表示」「人们普遍认为」 | 换成具体来源或具体人物的判断；没有来源就删 |
| 6 | 破折号/括号滥用 | 一句里塞两个「——补充说明」 | 每千字 ≤2 处；改成独立短句 |
| 7 | 高频虚词 | 仿佛、似乎、某种程度上、某种意义上、无疑、堪称、充满了、弥漫着、交织着 | 逐个替换为朴素动作或直接删 |
| 8 | 段落与句式整齐 | 每段 3-4 句、长短一致 | 故意打碎：插入一句短句、合并两段、单句成段 |
| 9 | 情绪过载与总结式收尾 | 「让我们共同期待……」「这一刻他终于明白了人生」 | 以事实、动作或一个具体细节收尾，不写结论 |
| 10 | 完美对称 | 正反观点永远平衡、转折永远是「然而」 | 真实思考有偏倚与不确定，保留它们 |

## 小说里特有的第四类：叙事腔

除了上面十类，AI 写故事还容易犯：

- **形容词形容情绪**：「他愤怒地吼道」「她悲伤地低下头」→ 删掉副词，只留动作与台词。
- **同义反复**：「他握紧了拳头，手心因为用力而发白，青筋暴起，指节咯咯作响」——四句讲同一件事，留一句最狠的。
- **五官全开**：每个场景都「视觉+听觉+嗅觉+触觉」配齐 → 改为「本场只需要哪两种感官」，其余删。
- **解释型旁白**：把角色的动机替读者总结一遍 → 删，让读者自己判断。
- **比喻撞车**：「像一只受惊的兔子/像潮水般涌来/空气仿佛凝固」→ 换成该角色职业/出身里才会有的喻体（木匠用词不会像诗人）。
- **对话过度完整**：每句话都是完整复句、礼貌周全 → 加打断、省略、答非所问。

## 中文高频词替换表（可加进自己的禁用词表）

| 别写 | 可以写成 |
|------|----------|
| 值得注意的是 / 值得一提的是 | （直接删） |
| 众所周知 / 不难发现 | （直接删） |
| 充满了 / 弥漫着 / 交织着 | 写具体事物：满是油垢的桌面 |
| 仿佛 / 似乎 / 某种意义上 | 写确定的动作或感受 |
| 不仅如此……更是…… | 只留后半句 |
| 复杂的情绪 / 五味杂陈 / 百感交集 | 写身体与动作：他把茶杯放下，又端起来，最后没喝 |
| 一丝 / 一抹 / 一缕（泛滥的量词） | 换成具体量：半指厚的灰 |
| 这一刻 / 此刻（频繁） | 删，或换成时间锚点：三更天的更鼓刚敲过 |
| 眼神里闪过一丝…… | 写动作后果：他别过脸去，很久没说话 |
| 心中暗暗 / 心底隐隐 | 删（内心戏直接写想法即可） |

## 改写流程（推荐四步）

1. **量化**：跑 `draft_diagnostics.py`，记录 AI 高频腔密度、句长变异系数、段落变异系数、重复表达。
2. **扫高频**：按上面的词表全文搜索，逐处判定——删、替换、还是作者本意要保留。
3. **打节奏**：合并/拆分段落，插入 1-3 处单句成段；把一个长句拆成两个短句，或反之。
4. **复核**：再跑一次脚本，确认高频腔密度下降、变异系数上升；把改动清单交给作者终审。

## 边界：不要为了「不像 AI」把文章改坏

- 不因为「这个词 AI 常用」就删掉本就贴切的表达；
- 不为了显得「人味」而故意加错别字、情绪化感叹或无意义口语；
- 不因为检测到某些统计特征就整段重写——**统计特征只能定位，不能定罪**；
- 作者的个人风格（哪怕很规整）优先于通用清单。

## 给 AI 的负面指令模板

写章节前把「不能写什么」说清楚，比事后改更有效：

> 本章禁止出现：值得注意、众所周知、仿佛、似乎、某种程度上、充满了、复杂的情绪、五味杂陈、眼神里闪过一丝、总结式结尾句。
> 禁止三段排比与「不仅……更是……」句式；禁止每段长度相同；禁止在章末写总结或升华。
> 每段开头不得重复使用同一个字；同一比喻不得出现两次。
> 情绪一律用动作、身体反应或台词呈现，不得直接命名情绪。
