# 角色塑造

仅在设计新角色、修改角色弧线，或诊断「角色扁平」「动机模糊」「配角工具人化」时读取。核心底线（五层设计法、「想要 vs 需要」框架）已内置于 SKILL.md，此处是完整展开。

> 相关指南：弧线与三幕结构的配合见[故事结构](craft-story-structure.md)；台词贴合身份与潜台词见[对话写作](craft-dialogue.md)；情绪与防御机制的写法见[情绪与潜台词](craft-emotion-and-subtext.md)。

方法论来源（转述）：麦基「人物本性在压力下的选择中显现」与对抗力量原则、K.M. 韦兰德的角色弧分类、唐纳德·马斯关于「独特/共鸣/动机」的角色创作建议。

## 一、人物塑造 ≠ 人物本性

- **塑造**：可观察的特征总和（外表、口音、职业、习惯、来历）。
- **本性**：**在压力下做出的选择**。压力越大，选择越暴露本性；在善恶、对错之间的选择不算选择（那不需要挣扎）。

所以写角色的正道不是"介绍他是什么人"，而是**不断把他放进两难**。读者记住的永远是选择，不是形容词。

## 二、五层设计法（由浅入深）

1. **原型定位**：理想主义者/犬儒/幸存者/守护者/追寻者……（不是好坏二分）
2. **外在 + 内在欲望**：长相、习惯性小动作、真正想要什么
3. **创伤与防御机制**：受过什么伤，用什么方式自保（冷漠/讨好/控制/逃避/攻击）——**防御机制就是性格缺陷的来源**
4. **矛盾性**：互相矛盾的特质（冷酷杀手养猫、温柔的母亲撒下弥天大谎）
5. **命运弧线**：通过磨难改变认识，不是"变强"，而是"重新认识自己"

## 三、想要 vs 需要

- **想要（表层目标）**：角色自以为的目标（报仇、发财、得到 ta 的爱）。
- **需要（深层成长）**：角色真正缺的、自己不知道的（放下仇恨、学会信任）。
- 好的结局：得到"需要的"，代价是放弃"想要的"；或得到"想要的"后发现不是自己真要的。

## 四、三种角色弧线

| 类型 | 走向 | 适用 |
|------|------|------|
| **正向弧** | 从错误信念 → 承认并改变（懦弱→勇敢、自私→牺牲） | 大多数商业小说 |
| **负向弧** | 拒绝改变 → 堕落或毁灭（警惕→猜忌→众叛亲离） | 悲剧、反派视角、警示故事 |
| **扁平弧** | 主角不变，世界被 ta 改变（侦探、老派英雄、信念坚定者） | 系列作、单元案、爽文主角 |

扁平弧不是"没写人物"，而是**让人物成为常量、让配角与世界去变**——前提是 ta 的信念足够有分量。

## 五、让角色立得住的四件事

- **独特**：一个别人没有的细节（职业习惯、口头禅、对某件小事的偏执）。
- **共鸣**：一个普世的情感缺口（被辜负、想被看见、怕失去）。
- **动机深度**：动机要能追溯到某段具体经历，而不是"他就是这样的人"。
- **能力匹配**：角色的能力要与题材设定的上限匹配，且必须"够得着"目标——否则读者不信。

## 六、语言指纹（最容易露馅的一层）

给每个重要角色定一张小表，写对话和内心独白时对照：

| 维度 | 取值范围 |
|------|----------|
| 句长 | 短促 / 中等 / 长句缠绕 |
| 词汇 | 书面 / 市井 / 行话 / 外语词 |
| 口头禅与禁忌词 | 有 / 无，分别是什么 |
| 礼貌度 | 敬语 / 平等 / 命令 |
| 信息密度 | 一句话只说一件事 / 一段话塞三层意思 |
| 情绪外显方式 | 直接 / 讽刺 / 沉默 / 转移 |

**检查法**：遮住说话人名字，读一段群戏对白——如果分不清谁在说，指纹就没建立。

## 七、配角与反派

- **配角也有智力**：对手越强，主角赢一次越有分量。不要让反派为了推动剧情突然降智。
- **配角功能清晰**：镜像（相似处境不同选择）/ 对照（相反性格相同困境）/ 催化（逼主角做决定）/ 承载主题。
- **反派是主题的对立面**：主角代表自由，反派就代表控制——不是"阻碍主角的人"。
- **可理解的反派**：让读者觉得"换我在那处境，可能也会……"，比纯恶更有力。
- 反派也要有"想要 vs 需要"，并且**自认为是自己故事里的主角**。

## 八、角色关系网

为每对重要关系写一句话情感本质（爱/恨/愧疚/崇拜/嫉妒）与变化方向（信任→背叛 / 敌对→惺惺相惜）。关系必须靠共同经历与代价推动，不能靠作者宣布。

## 九、角色卡最小字段

姓名 / 身份 / 年龄 / 外形关键字 / 想要 / 需要 / 创伤与防御 / 说话方式 / 当前状态（位置、情绪、持有物、未了之事） / 与主角关系 / 弧线方向 / 禁忌（绝不会做的事）

## 十、常见错误

| 症状 | 修法 |
|------|------|
| 角色扁平 | 加矛盾性 + 一个不愿提起的过去 |
| 动机模糊 | 把动机追溯到一件具体的事，并在正文里露一角 |
| 工具人配角 | 给 ta 一个与主角冲突的小目标 |
| 千人一腔 | 建语言指纹表，逐段遮名朗读 |
| 主角被动 | 每一章至少让 ta 主动做一次选择 |
| 突然降智 | 检查这个决定是不是"作者需要"而非"角色会选择" |
