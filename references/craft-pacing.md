# 节奏控制

仅在诊断「章节拖沓」「一路赶戏读者跟不上」「高潮不爽」或规划多章节奏起伏时读取。核心底线（快慢交替、高潮冲击力 = 压制时间 × 释放强度）已内置于 SKILL.md，此处是完整展开。

> 相关指南：单个场景的长度与体裁配比见[场景设计](craft-scene-design.md)；连载体的爽点密度与追读见[网文节奏与追读](craft-webnovel-rhythm.md)；段落均匀度的量化检查可用 `scripts/draft_diagnostics.py`。

## 一、节奏的本质

节奏不是"写快写慢"，是**信息投放与情绪刺激的频率**。持续高强度会让读者麻木，持续低强度会让读者离开。节奏需要像呼吸一样有起伏。

## 二、快与慢的手段

| 方向 | 手段 |
|------|------|
| **加速** | 删废话、短句、连续动作、缩短场景、减少内心独白、单句成段 |
| **减速** | 心理描写、环境渲染、多视角拉扯、拉长场景、增加身体感受细节、长句与复句 |

**段落长度就是油门**：短段落（1-3 行）自带加速感，长段落自带减速感。AI 生成的段落长度往往过于均匀（变异系数 < 0.4），需要手动打碎。

## 三、高潮前的"压制"

冲击力 ≈ 压制时间 × 释放强度。在高潮前先"压"：让主角受挫、局势恶化、读者替主角着急。压得越久，释放越爽——但中间必须给小爽点，否则读者会疲劳弃书（见网文节奏指南）。

**压制手段**：倒计时、资源耗尽、盟友离场、错误代价、反派先赢一局、主角受伤。

## 四、节奏断层与过渡

- 大冲突后**不能**立刻转日常（读者还在消化），需要一两段过渡承接情绪余韵。
- 反过来，长时间日常后要有一次"提神"事件，否则平路太长。
- 每章内部也要有起伏：起（承接）→ 承（升级）→ 转（转折/假结局）→ 落（爽点或钩子）。

## 五、章级模板（可直接写进章节任务卡）

1. **起承转爽（通用）**：起 300-500 字 → 承 800 字 → 转 300 字 → 爽 400 字 + 钩子
2. **过山车（战斗/危机）**：紧张 → 缓一口气 → 更紧张 → 假结局 → 最紧张 → 钩子
3. **信息递进（悬疑/解谜）**：线索 A → 结论 1 → 不对劲 → 线索 B 推翻结论 1 → 新推理 → 更大的秘密

## 六、冷却章

连续高潮之后需要一个"低强度但有信息"的章节（休整、感情戏、世界补充），作用是让读者恢复敏感度。冷却章不是水章：它必须推进关系、伏笔或角色状态。

## 七、节奏诊断

| 症状 | 检查 | 修法 |
|------|------|------|
| 拖沓 | 本章有没有「什么都没变」的段落 | 压缩或删除；把说明改成冲突 |
| 一路赶戏 | 有没有「续幕」（反应—困境—决定） | 补一段反应，让读者喘气 |
| 高潮不爽 | 压了几章？代价是什么？ | 加压制、加代价、抬高赌注 |
| 读着累 | 连续几章情绪峰值同型 | 换情绪类型、插冷却章 |
| 读着平 | 段落变异系数、句长变异系数 | 打碎段落、长短句交替 |
| 追读掉了 | 最近 3-5 章章末钩子 | 见[网文节奏与追读](craft-webnovel-rhythm.md) |

## 八、量化参考

跑 `python scripts/draft_diagnostics.py 章节.md` 后看三个数：

- **句长变异系数 < 0.5** → 句式偏单一；
- **段落变异系数 < 0.4** → 段落过于均匀（AI 痕迹）；
- **感官密度 < 8/千字** → 场景单薄（重要场景）。

数字只用来定位，改不改、怎么改仍由作者决定。
