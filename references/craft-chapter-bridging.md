# 章节衔接

仅在写章首章尾、处理 POV 切换、多线叙事换线，或诊断「章与章接不上」「读者每章都要重新适应」时读取。核心底线（章首自然顺承章尾、多线换线给明确 POV 标识与时间锚点）已内置于 SKILL.md。四种桥接方式（情绪/动作/悬念/时空）的示例表见 SKILL.md 阶段二「章首衔接」。

> 相关指南：POV 与时态规则见[视角、时态与叙述距离](craft-pov-and-distance.md)；「情绪断崖」背后的节奏考量见[节奏控制](craft-pacing.md)；长篇状态追踪见[上下文预算](context-budget.md)。

读者应该"不知不觉读完一章又一章"，而不是每章开头都要重新适应。

## 一、衔接的四个维度

写章首前，逐项对照上一章结尾：

| 维度 | 检查 |
|------|------|
| **时间** | 紧接着？过了多久？有没有明确交代？ |
| **空间** | 同一地点直接续接；换了地点要一两句锚定新空间 |
| **POV** | 同一角色情感延续；换了角色立刻锁定新 POV |
| **情绪** | 上章结尾的情绪余韵是什么？本章开头不能凭空跳变 |

## 二、常见问题

- ❌ **重复衔接**：本章开头大段复述上一章 → 信任读者记忆，最多一两句穿插提醒
- ❌ **零衔接**：上章在 A 场景告白，本章在 B 场景平静吃饭 → 哪怕一句过渡也能让读者跟上
- ❌ **情绪断崖**：上章沉重告别，本章欢快日常 → 转折可以成立，但要交代时间流逝与心理过程
- ❌ **时间线模糊**：读了三段还在猜"这是什么时候" → 时间锚点尽早给

## 三、时间跳跃的处理

- 跳过的时间如果是**低价值的**（赶路、等待），一句话带过即可：「三日后，车停在老家门前。」
- 跳过的时间里如果**发生了事**，必须补：要么在章首用一小段回忆/对话交代，要么干脆写成一章。
- 回忆、梦境、预言、闪回必须有清晰边界（空行 + 明确的进入/退出句），并与当前时态区分。

## 四、多线叙事换线

- 每条线各自保持连续性（读者等了很久的 A 线，更需要清晰衔接）。
- 换线公式：**新 POV 角色名/称谓 + 时间锚点（同时/三日后/此前）+ 该角色独有的关注点**。
- 各线之间的时间关系始终清晰（B 线此刻是 A 线的"三天前"还是"同时"？），建议在台账里记绝对日期。
- 换线顺序尽量跟随读者关心的紧迫度，而不是机械轮换。

## 五、章末 → 章首的"契约"

写章尾时就要想好下一章的第一个画面。做法是**在章节任务卡里同时写两格**：

- 本章结尾状态（情绪/地点/未解决问题）
- 下一章开头画面（第一句要落在哪）

这样即使隔几天再写，也不会断。

## 六、边界检查清单（写完一章后，把两章连起来读）

- [ ] 上一章最后 3 行 + 本章前 3 行连读，通顺吗？
- [ ] 时间、地点、POV、情绪四个维度都交代清楚了吗？
- [ ] 有没有用大段复述来"衔接"？
- [ ] 如果跳过了时间，跳过的部分是否有未交代的重要事件？
- [ ] POV 切换后，读者能否在三行内认出新视角角色？
- [ ] 多线时，本章与其他线的时间关系清楚吗？
- [ ] 本章结尾是否给下一章留下了可接的画面？
