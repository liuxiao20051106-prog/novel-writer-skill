# 场景设计

仅在搭建或修改具体场景、调整场景长度与节奏，或诊断「场景像流水账」「有事发生但没张力」时读取。核心底线（场景即冲突、无冲突的场景要么改要么删）已内置于 SKILL.md，此处是完整展开。

> 相关指南：整章快慢的宏观调度见[节奏控制](craft-pacing.md)；「进入」一步的感官与空间锚定见[代入感设计](craft-immersion.md)；场景内 POV 与视角越界见[视角、时态与叙述距离](craft-pov-and-distance.md)；情绪的具体写法见[情绪与潜台词](craft-emotion-and-subtext.md)。

方法论来源（转述）：杰克·比克汉姆《场景与结构》的「场景—续幕」模型、麦基的「场景必须有转折并改变价值」。

## 一、场景的本质

场景不是"发生事情的地方"，是**冲突展开的最小单位**：一个人物为了一个目标，遇到阻力，最后局势发生了变化（无论多小）。没有变化 = 没有场景。

## 二、场景—续幕模型（写作时最实用的节拍器）

**场景（行动单元）**
1. **目标**：本场景 POV 角色想要什么（要具体、当下、可判定成败）。
2. **冲突**：谁或什么在阻挡（外部阻力、他人反对目标、内心不敢）。
3. **灾难/转折**：结束时**没有得到**目标，或得到了但付出了意料之外的代价——迫使角色进入下一步。

**续幕（反应单元）**
4. **反应**：先给情绪（身体反应 → 情绪 → 思考，顺序不能反）。
5. **困境**：摆在他面前的选择，且每个选项都有代价。
6. **决定**：做出选择，指向下一个场景的目标。

节奏感来自二者的**配比**：高潮段落连续用「场景」（压迫—爆发），之后给一段「续幕」让读者喘气。AI 常见毛病是只写场景不写续幕，读起来"一路赶戏"。

## 三、场景的四步结构

- **进入**：一两句话做空间锚定 + 明确 POV 与当下时间。
- **冲突展开**：角色想要什么 → 阻力是什么 → 节拍（行动/反应）交替推进。
- **转折**：局势变化——离目标更近还是更远？知道了什么？对谁的看法变了？
- **退出**：停在"后果"上而不是"事情办完"上，让读者想知道接下来。

**两条老规矩**：从动作中间进入（能砍掉开头的前两段就砍），转折一旦完成立刻退出（能砍掉结尾的两段就砍）。

## 四、场景必须回答的五问

1. 谁的 POV？ta 现在想要什么？
2. 阻力来自哪里（人/环境/内心）？
3. 这场结束时，什么价值变了（+ 变 − 或 − 变 +）？
4. 这场留下了什么新信息或新问题？
5. 如果删掉这场，故事会缺什么？（答不上来就删）

## 五、场景长度与节奏

- **短场景（几百字）**：加速，适合动作、追逐、突发冲突。
- **长场景（几千字）**：减速，适合情感重场、复杂谈判、关键决策。
- **有意变化**：紧张场景后给长一点的喘息场景，反之亦然；段落长度也随之变化。

| 体裁 | 快:慢 参考比 | 说明 |
|------|-------------|------|
| 爽文/热血 | 3:1 | 密集冲突，偶尔喘息 |
| 言情 | 2:2 | 情感拉扯需要空间 |
| 悬疑 | 1:3 | 慢铺氛围，快用于揭露 |
| 正剧/文学 | 1:1 | 张弛均衡 |

## 六、场景诊断表

| 症状 | 病因 | 修法 |
|------|------|------|
| 流水账 | 没有目标或没有阻力 | 补目标与阻力，或删场景 |
| 有事发生但不紧张 | 角色太容易成功 | 加阻力、加代价、加时间压力 |
| 场景拖沓 | 进入太晚 / 退出太迟 | 砍头砍尾，从冲突处开始 |
| 一路赶戏 | 缺续幕（反应—困境—决定） | 在两场之间补一段反应 |
| 读者跳出 | POV 或叙述距离跳变 | 见[视角、时态与叙述距离](craft-pov-and-distance.md) |
| 打完就忘 | 没有价值变化 | 明确写出「什么从 + 变成 −」 |
