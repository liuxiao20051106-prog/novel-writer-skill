# 视角、时态与叙述距离

仅在确定/切换 POV、处理多线叙事、诊断「视角跳了」「距离忽远忽近」「时态混乱」时读取。核心底线（同一场景不换 POV、POV 与时态全篇统一、多线换线给明确标识）已内置于 SKILL.md。

> 相关指南：感官与共振的写法见[代入感设计](craft-immersion.md)；多线之间的章节边界见[章节衔接](craft-chapter-bridging.md)；情绪的深浅与叙述距离联动见[情绪与潜台词](craft-emotion-and-subtext.md)。

## 先定四件事，全书不改

| 决策 | 选项 | 取舍 |
|------|------|------|
| 人称 | 第一人称 / 第三人称有限 / 第三人称全知 / 第二人称 | 网文默认第三人称有限；第一人称声音强但难写多线；全知易失代入感 |
| POV 数量 | 单 POV / 多 POV | 多 POV 要约定章节级或场景级切换，禁止段内切换 |
| 时态 | 过去时 / 现在时 | 中文不显性标记时态，但「了/过/正在」的用法必须统一 |
| 叙述距离 | 见下节四档 | 同一部作品可以有主轴距离 + 局部调整，但不能随机漂移 |

## 叙述距离四档（最容易被忽略的旋钮）

叙述距离 = **时间距离**（事情发生多久后讲）× **心理距离**（读者离角色意识多近）。

| 档位 | 时间距离 | 写法 | 用途 |
|------|----------|------|------|
| **1 场景内·贴身** | 正在发生 | 直接呈现动作、感官、未成形的念头 | 高潮、危局、情绪峰值 |
| **2 场景内·近距** | 正在发生，带少量解释 | 动作 + 一句心理澄清 | 绝大多数正文 |
| **3 事后回顾·中距** | 事后 | 概括一段经历，允许带评价语气 | 过渡、压缩低价值过程 |
| **4 远景·全知** | 很久以后/非角色视角 | 概述、时代背景、跨角色比较 | 卷首语、历史交代、收束 |

**用法**：一章里以 2 档为主，关键处推进到 1 档，低价值过程用 3 档带过。突然从 1 档跳到 4 档会让读者被"弹"出故事。

**诊断**：如果读者说「前面很代入，中间突然出戏」，八成是距离档位跳变，而不是文笔问题。

## POV 规则

- 一个场景只有一个 POV 角色的「内部信息」。其他人物的内心只能通过外部信号推断（表情、动作、台词）。
- **禁止视角越界**：POV 角色看不到/听不到的东西不能写；别人背地里的行动不能写。
- **知情权分层**：区分「作者知道 / POV 角色知道 / 读者已经知道」，任何叙述不能越权（也是悬念公平性的底线，见[悬念与伏笔](craft-suspense-foreshadowing.md)）。
- 换 POV 的合法位置：新场景、新章节、明确分隔符之后。**换 POV 后第一段必须立刻锁定新角色**：名字/称谓 + 该角色独有的关注点（木匠先注意榫头，医生先看手）。
- 同一事件多 POV 复述时，第二次呈现必须带来新信息或新的认知落差，否则删。

## 第一人称的额外约束

- 不能写「他当时想……」这类全知信息；一切外部心理只能靠观察与猜测。
- 叙述者可以不可靠，但不可靠之处必须留下可回溯的线索（否则读者觉得被骗）。
- 「我」的声音要稳定：词汇量、自嘲程度、知识边界前后一致。

## 多线叙事

- 每条线有自己的**当前时间锚点**；换线时第一段给出「同时/三日后/此前」的提示。
- 换线的顺序尽量跟随读者关心的紧迫度，而不是机械轮换。
- 各线篇幅差距不要长期悬殊（除非是有意的伏笔线）。
- 汇合前，每条线的「价值变化」都要清楚；汇合时才会有化学反应。

## 常见错误与修法

| 症状 | 原因 | 修法 |
|------|------|------|
| 读者不知道「现在是谁在看」 | 换 POV 无标识 / 段内跳视角 | 场景边界换 POV；首段锁定角色 |
| 上帝视角泄露 | 写了 POV 角色不可能知道的事 | 改为角色推测，或换到知情的 POV |
| 距离忽远忽近 | 同一段内混用概括与贴身细节 | 概括与呈现分段，或统一到同一档位 |
| 时态混乱 | 「了/过/正在」混用、回忆段没有边界 | 回忆用独立段落 + 明确的边界句 |
| 多线时间对不上 | 各线缺少绝对日期 | 建立时间台账（见[长篇连续性](project-continuity.md)） |

## 写前检查

- [ ] 本章 POV 是谁？全书是否统一人称与时态？
- [ ] 本章以哪一档叙述距离为主？关键场景是否推到了 1 档？
- [ ] 有没有写出 POV 角色看不到/听不到的信息？
- [ ] 若换 POV，第一段是否立刻锁定了新角色？
- [ ] 多线时，本章在时间轴上与其他线是什么关系？
