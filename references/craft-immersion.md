# 代入感设计

仅在自查或修复「读者出戏」「代入不进去」问题，或设计高代入感的关键场景时读取。核心底线（五层体系：视角锁定 + 感官沉浸 + 情感共振 + 处境设计 + 错误规避）已内置于 SKILL.md，此处是完整展开。

> 相关指南：「情感标签→具体行为」的语言层写法见[文笔与风格](craft-prose-style.md)；POV 边界与叙述距离四档见[视角、时态与叙述距离](craft-pov-and-distance.md)；微观张力与情绪层级见[情绪与潜台词](craft-emotion-and-subtext.md)。

代入感不是靠一个技巧，而是多层同时发力。任一层塌了，读者就会"感觉到自己在读书"。

## 1. 视角锁定——让读者住在主角脑子里

- 首选第三人称有限视角：读者只能感知 POV 角色能感知的东西。
- 第一人称声音强，但牺牲多线灵活性；全知视角容易失代入。
- **同一场景不换 POV**，换 POV 至少以场景/章节为边界，并立刻锁定新角色。
- POV 选择原则：谁在现场且情感投入最深，就用谁。

## 2. 感官沉浸——让读者感觉自己在现场

- 每个重要场景至少调用三种感官，但**不必五感齐全**——选本场最需要的。
- **身体先于大脑**：先写生理反应，再写意识判断。
- **空间锚定**：场景开头一两句把读者放进空间（大小、光线、气味、可用的出口）。
- 感官要贴着角色的关注点走：害怕的人先听见声音，饿的人先闻到味道。

## 3. 情感共振——让读者的心和角色一起跳

- 用具体行为替代抽象情绪（见情绪与潜台词）。
- **"普通人时刻"**：宏大剧情里插入平凡的真实瞬间——决战前系鞋带时手在抖、冷酷杀手路过花店放慢脚步。
- **先建立，再威胁**：先让读者喜欢上一个人/一件东西/一种生活，再让它受威胁。没有建立就没有失去。
- **代价要真**：做错事有后果，受伤留痕迹，失去的东西不轻易回来。

## 4. 处境设计——让代入变得容易

- **起点要低**：初始处境越接近普通人的情感体验，越容易代入。
- **选择要难**：读者代入的是"艰难抉择的过程"，不是"英明神武的结果"。
- **代价要真**：每一个收获都要付代价，且代价可被读者感知。
- **能力匹配**：主角要"够得着"目标，读者才会相信 stakes。

## 5. 微观张力——让平静的段落也不平

即使没有冲突，也要有小小的不安（未回答的问题、压迫性细节、言行不一、临近的后果）。随机抽三段都"很平静"，读者就在平路上走——平路超过三章，追读必掉。详见[情绪与潜台词](craft-emotion-and-subtext.md)。

## 6. 常见的代入感破坏

| 破坏 | 表现 | 修法 |
|------|------|------|
| 上帝说明 | 叙述者口吻解释世界观 | 通过角色视角自然暴露，或拆到冲突里 |
| 情感标签 | 直接说出情绪名 | 换成身体反应与动作 |
| 上帝视角预警 | 「他不知道，这个决定将改变一生」 | 删除；让读者与角色同步体验 |
| 角色降智 | 为推进情节做蠢决定 | 检查动机是否"作者需要" |
| 巧合过多 | 连续靠巧合推进 | 巧合只能制造问题，不能解决问题 |
| 过度内心独白 | 大段思考 | 分散到行动、对话、感官里 |
| 叙述距离跳变 | 一段贴身、一段远景 | 见[视角、时态与叙述距离](craft-pov-and-distance.md) |
| 术语轰炸 | 开局一堆专有名词 | 设定跟着冲突一点点放（见开篇钩子） |

## 7. 代入感自查（每章写后）

- [ ] 读者知道"我是谁"（POV 清晰稳定）吗？
- [ ] 本场能感受到什么（感官是否够、是否贴着角色关注点）？
- [ ] 角色的反应像真实的人吗（先身体、后判断）？
- [ ] 有没有可以改成角色视角的"上帝说明"？
- [ ] 有没有"先建立再威胁"的顺序？
- [ ] 连续三段是否都缺乏不安？
